# 아빠어디가 시연 서버

휴대폰 가족방, 장소 검색, 공유 코스와 개인 저장 장소를 제공하는 시연용 서버다. Node.js 24 이상에서 `npm ci` 후 `npm test`로 검사하고 `node dev.mjs`로 실행한다. 서버는 localhost에 바인딩된다. 외부 시연에는 별도의 HTTPS 연결이 필요하다.

기본 설정에서는 가족방·초대·제안·공유 코스를 메모리에 보관한다. FAMILY_LOCAL_ARCHIVE_DIR를 지정하면 암호화 로컬 보관을 사용한다. 메모리 모드는 재시작하면 사라지며, 임시 터널 주소도 바뀔 수 있다. 차량 앱은 빌드 시 정한 서버 주소로 연결한다. 실시간 차량 위치와 실제 주행 길안내는 아직 제공하지 않는다.

장소 검색에는 `KAKAO_REST_API_KEY`가 필요하다. `ROOM_CREATE_SECRET`은 차량 방 생성 요청을 제한한다. 비밀값은 코드·로그·채팅에 기록하지 않는다.

선택적으로 `AWS_REGION`, `COGNITO_USER_POOL_ID`, `COGNITO_CLIENT_ID`, `COGNITO_AUTH_DOMAIN`, `SAVED_PLACES_TABLE`을 함께 지정하면 개인 저장 장소가 Cognito와 DynamoDB에 연결된다. 서버 실행 환경에는 해당 테이블에 대한 AWS 자격 증명이 필요하다. 설정이 없으면 계정 화면에서 준비 중임을 표시하고 장소는 휴대폰에만 저장된다. Cognito 콜백 URL은 외부 주소의 `/account`와 일치해야 한다. 테스트용 임시 터널 주소는 운영 주소가 아니다.

계정 저장 장소는 해당 계정에만 보이지만, 사용자가 가족방에 제안한 장소는 해당 가족방에 공유된다. 가족방과 코스의 로컬 보관은 선택 설정이며 운영용 호스팅·백업·실제 이용자 검증은 별도 작업이 필요하다.

안내 종료 후 가족방에서 완료한 경로를 계정별 추억으로 저장하거나, 제목을 적어 공개 코스로 공유할 수 있다. 개인 추억은 계정별 장소 순서만 저장하며 사진을 포함하지 않는다. 공유 코스 역시 장소와 소개만 공개한다.

가족방 사진은 해당 방의 유효한 참가자 토큰으로만 접근할 수 있고 JPEG로 축소해 서버 메모리에 최대 8장 보관한다. 초대 링크를 받은 사람은 가족방에 참여할 수 있으므로 링크는 신뢰하는 가족과만 공유한다. 메모리 모드의 사진은 방 만료 또는 서버 재시작 시 사라진다. 로컬 보관 모드에서는 암호화된 가족방 사진을 복원한다. 차량에서는 해당 방 사진을 삭제할 수 있고 휴대폰 참가자는 자신이 올린 사진만 삭제한다. 공개 코스 목록이나 가져온 경로에 사진 데이터는 포함되지 않는다.

좋아요는 로그인 계정당 코스별 한 번만 반영되며 공개 목록은 좋아요 순으로 정렬된다. 좋아요와 공유 코스는 아직 메모리에만 존재하므로 서버가 재시작되면 초기화된다. 인기 순위는 실제 사용자들의 현재 좋아요 수를 의미하며 실시간 트렌드 분석은 아니다.

## 커뮤니티: 후기와 요즘 인기

- 공유 코스에는 로그인한 사람이 별점(1~5)과 후기를 남길 수 있다. 계정당 코스별 하나이고 다시 쓰면 고쳐진다. 읽기는 누구나 할 수 있고, 화면에는 직접 적은 이름만 보인다.
- `GET /api/public/courses?sort=trending|popular|new&kind=community|official`로 보는 순서와 종류를 고른다. `GET /api/public/trending`은 요즘 활동이 많은 지역과 코스를 돌려준다.
- "요즘 인기"는 최근 7일 동안 이 앱 안에서 생긴 좋아요(1점), 후기(2점), 실제 길 안내에 쓰임(3점)을 더하고 이틀마다 절반으로 줄인 값이다. 앱 밖의 실제 방문객 수나 검색량이 아니다.
- "지역 추천"은 `curated-courses.mjs`의 코스로, 관광 안내 자료를 참고해 시연용으로 다시 짠 것이다. 지자체가 이 순서 그대로 추천한다는 뜻이 아니다. 한국관광공사 TourAPI 같은 공식 자료와 연결하려면 별도의 키와 작업이 필요하다.
- 좋아요·후기·최근 활동은 로컬 보관(`FAMILY_LOCAL_ARCHIVE_DIR`)을 켰을 때만 재시작 뒤에도 남는다.

## 코스 공유의 책임 장치

- 공개할 때 장소별로 뺄 수 있다(`exclude`). 공개되는 것은 고른 장소의 이름·주소·좌표와 여행 취향 태그다. 가족 사진과 이름은 나가지 않는다.
- 코스에는 올린 가족방이 기록되고(공개 응답에는 나가지 않음), 그 방의 사람만 `DELETE /api/courses/:id`로 내릴 수 있다. 한 방에서 3개까지, 같은 장소 구성은 한 번만 올릴 수 있다.
- 로그인한 계정은 `POST /api/courses/:id/report`로 신고할 수 있고, 서로 다른 3명이 신고하면 목록에서 숨는다(올린 방에는 계속 보인다).
- "요즘 인기" 점수는 사람(좋아요·후기)이나 가족방(길 안내)당 종류별로 한 번만 세고, 취소하면 뺀다. 점수가 3 이상일 때만 "요즘 인기" 표시가 붙는다.
- 지역 이름은 알려진 시·도 주소일 때만 만든다. 예시가 아닌 코스만 있는 지역은 코스가 2개 이상일 때 지역 목록에 오른다.
- 가족방은 제안·투표·사진·경로 변경이 있을 때마다 만료가 12시간 뒤로 미뤄진다. 여행을 끝내면 지난 들르는 곳은 정리된다.

## 가족방의 여행 묶음

- 경로가 처음 생기면 가족방 안에 여행 묶음이 열리고, 안내를 끝내면(그냥 끝내도) 그 여행이 `trips`에 남는다. 가족방당 최근 20개까지, 사진은 여행마다 8장까지다.
- 사진은 지금 여행에 담기고, 여행 중이 아니면 '여행 전 사진'으로 모인다. `POST /api/photos`에 `tripId`를 주면 지난 여행에도 사진을 더할 수 있다.
- 추억 저장(`POST /api/profile/memories`)과 코스 공유(`POST /api/courses`)는 `tripId`로 여행을 고를 수 있다.
- 추천받은 코스(가족 공유 코스나 참고 코스)로 시작한 여행은 `fromCourse`가 기록되고, 다시 공유할 수 없다(409). 대신 그 코스에 좋아요·후기를 남기고 추억으로 저장한다. 차에서 '공유'를 골라도 '후기 남기기'(`REVIEW`)로 처리된다.
- 좋아요는 가족이 공유한 코스와 관광 안내를 참고한 코스에 누를 수 있다. 시연 예시 코스에는 누를 수 없다.

## 차량 연결 코드와 응답 코드

- 차량 연결 코드는 숫자 6자리이고 10분 동안 한 번만 쓸 수 있다. 연결 요청은 IP당 분당 5번으로 제한된다.
- 오류 응답은 401(가족방에 다시 참여 필요), 403(권한 없음), 404(없음), 409(지금 상태로는 할 수 없음), 429(요청이 많음), 그 밖은 400이다. 차량 앱은 401을 받으면 가족방이 닫힌 것으로 보고 처음 화면으로 돌아간다.
