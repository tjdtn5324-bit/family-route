# 휴대폰 접속과 서버 재시작

PLEOS VM은 PC의 `http://10.0.2.2:8789`에 연결합니다. 휴대폰은 Cloudflare 임시 HTTPS 주소로 같은 서버에 접속합니다. 차량의 `가족` 메뉴는 지금 터널 주소의 QR을 보여 줍니다. 주소가 바뀌면 새 QR을 찍으면 됩니다. 로그인은 각자 계정으로 하므로 주소가 바뀌어도 계정 설정을 따로 바꿀 필요가 없습니다.

시연 PC에서는 Windows 로그인 시 시작프로그램의 **AppaEodiga Preview** 바로가기가 `tools/start-preview.ps1`을 실행합니다. 서버와 터널이 꺼져 있으면 다시 켜고, 터널 주소가 1분 넘게 응답하지 않으면 터널을 새로 엽니다. 다른 프로그램이 8789 포트를 쓰면 그 포트를 외부에 연결하지 않습니다. 터널 상태 확인 포트는 127.0.0.1:20241입니다.

서버만 다시 시작하려면 `tools/restart-preview.ps1`을 실행합니다. 계정·가족·여행·사진은 `.runtime/v2-8789/`의 암호화 파일에서 복원됩니다. 이 폴더의 키와 보관 파일을 한 쌍으로 유지해야 합니다. `FAMILY_V2_ARCHIVE_DIR`로 다른 위치를 지정할 수 있습니다.

검색과 경로는 이 시연 서버에서 모의 자료입니다(부산 예시 장소, 직선 경로). 카카오나 AWS로 요청을 보내지 않으므로 비용이 생기지 않습니다.
