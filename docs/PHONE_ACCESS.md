# 휴대폰 접속과 서버 재실행

Pleos 에뮬레이터는 PC의 `http://10.0.2.2:8789`에 연결합니다. PC 브라우저는 `http://127.0.0.1:8789`를 사용합니다. 이 로컬 주소를 다른 휴대폰에 공유해도 접속되지 않습니다.

## 같은 Wi-Fi에서 참여

PowerShell에서 다음과 같이 서버를 실행하고 PC의 사설 IP 주소로 접속합니다. PC 방화벽이 접속을 막는 경우 해당 포트의 로컬 네트워크 접근 설정을 확인합니다.

```powershell
$env:FAMILY_LAN = "1"
node tools/preview-phone.mjs 8789
```

휴대폰 주소는 `http://PC의_사설_IP:8789`이며 서버 시작 시 표시됩니다. 차량은 `/api/invite-origin`에서 접속 가능한 주소를 받아 초대 QR에 사용합니다. 같은 Wi-Fi에 연결되어 있어야 합니다.

## 서로 다른 곳에서 참여

Cloudflare의 `cloudflared` 등을 별도로 설치하고 로컬 서버를 HTTPS 주소에 연결할 수 있습니다. 서버가 실행 중인 상태에서 다음과 같이 실행하면 **로컬 서버가 인터넷에 공개**됩니다. 홈페이지는 주소를 아는 사람이 열 수 있으며 가족 자료는 로그인·가족방 권한으로 보호합니다.

```powershell
cloudflared tunnel --no-autoupdate --protocol http2 --metrics 127.0.0.1:20241 --url http://127.0.0.1:8789
```

차량은 터널과 서버의 instance가 일치하는지 확인한 뒤 공개 주소를 사용합니다. 임시 주소는 바뀔 수 있으므로 변경 후 새 초대 링크나 QR을 공유합니다. 주소가 바뀌면 브라우저 로그인이 다시 필요할 수 있지만 서버에 저장한 계정과 가족방은 유지됩니다. 터널이 종료되면 해당 임시 주소로는 접속할 수 없습니다.

`node tools/demo.mjs` 또는 `demo.cmd`/`sh demo.sh`는 서버와 APK 설치를 도우며, cloudflared가 있으면 임시 터널을 사용하고 없으면 같은 Wi-Fi에 공개합니다. 인터넷 공개가 필요 없으면 위 수동 실행 방법을 사용하세요.

## 자료 보관과 재실행

`.runtime/v2-8789/family-archive.enc`와 `archive.key`를 함께 보관하면 같은 서버를 다시 실행할 때 계정·가족·여행·사진을 복원합니다. GitHub에는 올리지 않습니다. `FAMILY_V2_ARCHIVE_DIR`로 다른 저장 경로를 지정할 수 있습니다.

현재 개발 PC에는 `tools/start-preview.ps1`을 실행하는 시작프로그램 설정이 있지만, 저장소를 받은 다른 PC에 자동 설치되는 것은 아닙니다. 다른 PC에서는 서버와 터널을 직접 실행해야 합니다.

## 검색과 경로

키가 없으면 내장 장소·시연 경로를 사용합니다. 서버에 카카오 REST 키를 설정하면 실제 장소 검색과 도로 경로를 요청합니다. 도로 요청 실패 시 시연 경로로 대체되므로 실차 안내로 사용하지 마세요. 현재 v2 서버의 계정·가족·사진 저장에는 AWS 로그인이 필요하지 않습니다.
