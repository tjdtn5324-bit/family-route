# 계정·가족·차량 권한

현재 v2 서버는 AWS Cognito가 아니라 자체 이메일·비밀번호 계정을 사용합니다. 비밀번호는 scrypt 해시로, 서버 세션 토큰은 해시로 보관합니다. 휴대폰은 HttpOnly·SameSite=Strict 쿠키로 로그인합니다. 주소가 바뀌면 다시 로그인해야 할 수 있지만 같은 서버에 저장한 계정을 다시 가입할 필요는 없습니다.

## 가족방과 자료 접근

| 자료 | 접근 범위 |
| --- | --- |
| 계정·개인 설정 | 본인 계정 |
| 가족방 | 소속 구성원과 해당 가족에 연결된 차량 |
| 여행·제안·이야기·가족 사진 | 소속 가족방에서 권한을 확인한 구성원과 연결된 차량 |
| 공개 코스의 장소·제목·소개 | 로그인 여부와 관계없이 열람 가능 |

- 한 계정이 여러 가족방에 소속될 수 있습니다. 화면을 다른 곳으로 이동하는 것은 탈퇴가 아닙니다.
- 현재 선택한 가족방은 로그인 세션별로 관리합니다. 같은 계정의 두 휴대폰이 서로 다른 가족방을 선택할 수 있습니다.
- 초대 링크·QR은 가족방 참여에 사용하며, 초대한 사람의 계정 세션을 공유하지 않습니다. 각자 자신의 계정으로 참여합니다.
- 다른 가족방의 사진을 ID만 알아서 가져갈 수 없도록 서버에서 소속을 검사합니다. 공개 코스에는 가족 사진·이름·메시지를 포함하지 않습니다.
- 가족 관리자는 구성원 관리 권한을 가집니다. 관리자가 탈퇴하려면 위임이 필요하며, 마지막 구성원이 탈퇴하면 가족 자료가 삭제될 수 있으므로 화면의 안내를 확인해야 합니다.

## 제안과 운전자 확인

- 가족 구성원은 목적지·경유지를 제안하고 공감·댓글을 남길 수 있습니다.
- 관리자가 직접 제안해도 그 자체로 자동 확정되지 않습니다. 일반 준비 완료나 공감만으로 승인하지 않습니다.
- 제안 확정은 지정 운전자 또는 연결된 차량이 수행합니다. 차량의 ‘가족 제안 담고 출발’은 대기 제안을 함께 승인하는 명시적 버튼입니다.
- 여행 수정·삭제 권한과 제안 승인 권한은 동일하지 않을 수 있으며, 서버가 작업별로 검사합니다.

## 차량 연결

- 차량에서 가족방을 만들거나, 휴대폰 가족방에서 발급한 6자리 차량 연결 코드를 입력합니다.
- 차량은 사람 계정으로 로그인하지 않고 별도의 차량 토큰을 사용합니다. 토큰은 Android Keystore로 암호화해 기기에 보관합니다.
- 차량에는 여러 가족 연결이 남으며 선택한 가족방의 여행과 사진만 표시합니다. 방 전환 시 이전 사진 캐시와 선택을 비웁니다.
- 가족 연결 해제는 다른 가족방의 연결이나 단독 길찾기를 지우지 않습니다.
- Pleos 차량 위치는 동의 후 수신하며, 새 길찾기와 여행 출발에 사용합니다. 연속 위치 이력은 저장하지 않습니다. 가족 여행 출발지는 해당 가족 여행에 저장됩니다.

## 보관과 복원

현재 시연 서버는 `.runtime/v2-8789/family-archive.enc`와 `archive.key`를 사용합니다. AES-256-GCM으로 상태를 암호화하고, 파일과 키를 함께 보관하면 서버를 다시 실행할 때 계정·가족·여행·사진을 복원합니다. 둘 중 하나를 삭제하거나 분실하면 복원이 어려워집니다.

이 폴더와 키는 Git에서 제외합니다. 암호화 파일은 별도의 원격 백업이나 클라우드 운영 서버를 의미하지 않습니다. PC 재부팅 뒤 서비스에 접속하려면 서버와 필요한 터널이 다시 실행되어야 합니다.
